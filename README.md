# Ruka Modular - Landing Page 🏠

Una *Landing Page* institucional tipo *One Page* desarrollada a medida para **Ruka Modular**, una empresa enfocada en el diseño y construcción de arquitectura modular. El proyecto está enfocado en una alta calidad visual, rendimiento y una excelente experiencia de usuario (UX).

🔗 **[Ver proyecto en vivo](https://tu-usuario.github.io/ruka-modular/)**

## 🚀 Características principales

* **Internacionalización (i18n):** Sistema de cambio de idioma dinámico (Español / Inglés) desarrollado desde cero, que actualiza textos y *placeholders* sin recargar la página.
* **Diseño 100% Responsivo (Mobile First):** Interfaz completamente adaptable a dispositivos móviles, tablets y escritorio.
* **Componentes Interactivos Custom:** 
  * Carrusel de testimonios con avance automático y controles manuales.
  * Menú de navegación fijo (*sticky navbar*) que reacciona al scroll.
  * Menú hamburguesa para vista móvil.
* **Widget de WhatsApp:** Chat flotante simulado que redirige directamente a la API de WhatsApp para iniciar conversaciones.
* **Navegación Fluida:** Implementación de *smooth scrolling* con compensación de altura para el menú superior.

## 🛠️ Tecnologías y Herramientas

* **HTML5:** Estructura semántica.
* **CSS3:** Metodologías modernas, **CSS Flexbox**, **CSS Grid**, variables, animaciones CSS y *Media Queries*.
* **JavaScript (Vanilla ES6):** Manipulación del DOM, *Event Listeners*, *Timers* (setInterval/clearInterval) y lógica de estado sin uso de librerías externas.
